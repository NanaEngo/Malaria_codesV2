## Build Workflow

### Step 1: Run Build Script

```bash
cd /home/vital/Documents/GitHub/Malaria_codesV2
bash scripts/build_zenodo_packages_batch.sh
```

This script:
1. Creates directory structures for P3, P4, P5
2. Copies data, results, scripts, documentation
3. Generates `sha256sums.txt` for each package
4. Reports file counts and sizes

### Step 2: Verify Packages

For each package:

```bash
cd ProjectX/zenodo_package_PX
sha256sum -c sha256sums.txt
```

### Step 3: Reserve DOIs

- **P3**: Already reserved https://doi.org/10.5281/zenodo.19608875
- **P4**: Need to reserve on Zenodo
- **P5**: Need to reserve on Zenodo

To reserve a DOI:
1. Go to https://zenodo.org
2. Click "New upload"
3. Fill basic metadata (title, authors)
4. Click "Reserve DOI" (do not upload yet)
5. Copy DOI and update MANIFEST.json and README.md

### Step 4: Upload to Zenodo

Follow `UPLOAD_INSTRUCTIONS.md` in each package:
1. Access reserved deposit
2. Fill complete metadata
3. Upload files (drag-and-drop or ZIP)
4. Verify checksums
5. Publish

### Step 5: Update Manuscripts

Insert DOIs in Data Availability sections:

```latex
\section*{Data Availability}
All data and analysis scripts are available at Zenodo: \url{https://doi.org/10.5281/zenodo.XXXXX}.
```
