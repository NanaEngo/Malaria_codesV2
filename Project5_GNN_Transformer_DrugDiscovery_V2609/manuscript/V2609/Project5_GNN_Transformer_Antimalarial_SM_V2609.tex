\section{Orthogonal LISH mechanism-of-action benchmark}
\label{sec:lish_si}

The molecular representations benchmarked in the main text (ECFP4, GIN, GIN--TFP, GIN--TNE, ChemBERTa) encode chemical structure. Whether those structural features capture pharmacological mechanism is tested here using the LISH mechanism-of-action (MoA) challenge \citep{lish_moa_2019}, which asks whether gene-expression and cell-viability readouts---phenotypic proxies of drug action---can predict MoA class. The public LISH release carries no versioned drug-to-SMILES mapping; the two benchmarks are structurally disjoint, and the LISH phenotype baseline cannot be compared to the molecular ROC-AUC figures in the main text. This section establishes an orthogonal pharmacological reference ceiling that any future structure-to-MoA model must exceed.

\subsection{Data and preparation}

We drew on the public LISH MoA training release \citep{lish_moa_2019}, available from the challenge repository at \url{https://github.com/LISHarvard/moa_challenge}. After aggregating repeated assay observations to the drug level, the working table retained \num{772} gene-expression features, \num{100} cell-viability features, and three experimental-condition summaries.

The scored endpoint comprises \num{206} MoA labels across \num{3289} drugs \citep{Trapotsi2022MoA}. Multi-label annotations (each drug may carry several MoA labels) cause per-label classifier performance to vary; labels with insufficient test-set variation are excluded from the macro average on a per-fold basis. No versioned drug-identifier-to-SMILES mapping exists in the public release, so the data set could not be used to train or evaluate any molecular model.

The macro-AUROC of \num{0.6435} represents the ceiling that any future structure-based MoA predictor must surpass on the same fold grid. Approximately \qty{72}{\percent} of the \num{206} MoA labels retain discriminative signal under drug-grouped splits (\numrange{140}{155} labels per fold with sufficient test-set variation); the remainder are too rare for fold-level AUROC and are excluded from the macro average. This baseline is deliberately weak---unweighted per-label logistic regression on phenotype features---so that any upstream molecular method that fails to exceed \num{0.6435} macro-AUROC on the same grid provides no evidence of pharmacological representation superiority.

\section{Calibration metrics for the molecular benchmark}
\label{sec:calibration_si}

Predictive accuracy (ROC-AUC) and predictive reliability (calibration) are distinct properties: a model may rank compounds correctly yet assign poorly calibrated probabilities. Calibration metrics were computed from fold-level test predictions pooled across the extended campaign, yielding \num{99180} test records per configuration (five seeds $\times$ five folds, for each of four model families). ECE rises from approximately \num{0.03} on the random split to \numrange{0.07}{0.13} on the scaffold and novel-scaffold partitions for every model family (\Cref{tab:s2_calibration}). ChemBERTa exhibits the largest degradation under scaffold shift (ECE \numrange{0.12}{0.13}), consistent with its greater sensitivity to structural distribution shift (\Cref{MAIN-tab:h1}). This degradation is the empirical basis for the $\mathrm{ECE} > 0.08$ recalibration trigger in the Conformal Triage Filter (\cref{sec:triage_code_si}): when batch-level confidence breaches this threshold, post-hoc Platt scaling or isotonic regression must be applied before any hard-cutoff routing decision.

\section{Light GNN hyperparameter sensitivity and capacity defense sweep}
\label{sec:gnn_sensitivity_si}

A persistent objection to the GNN underperformance documented in the main text is that it may reflect suboptimal hyperparameter selection rather than a fundamental expressivity ceiling. A systematic capacity defense sweep (SLURM Job 15617) was executed on the canonical scaffold split with the same frozen \num{5}-fold $\times$ \num{5}-seed protocol. The base GIN architecture \citep{xu2019gin} was evaluated across hidden dimensions $h \in \{\num{64}, \num{128}, \num{256}\}$ and dropout rates $d \in \{\num{0.1}, \num{0.2}\}$, bracketing the canonical configuration ($h=\num{128}$, $d=\num{0.1}$) from both below and above. Each configuration produced \num{25} fold--seed records with finite AUC.

As shown in \Cref{tab:s3_gnn_sensitivity}, mean scaffold ROC-AUC remains strictly bounded between \num{0.8000} and \num{0.8081}---a range of \num{0.0081} AUC points. The per-seed standard deviation (\numrange{0.0118}{0.0160}) exceeds the inter-configuration spread, indicating that performance variation is dominated by fold-level stochasticity, not capacity choices. All three configurations remain below the ECFP4--RF scaffold reference (\num{0.8300} $\pm$ \num{0.0023}); the gain from enlarging the GIN capacity is flat-to-negative, consistent with the honest-negative verdict. The extrapolation gap is therefore fundamentally constrained by the 1-WL expressivity limit rather than by hyperparameter under-tuning. The TFP rescue documented in the main text (\cref{MAIN-tab:structural_complexity}) confirms this interpretation from the opposite direction---if the deficit were a capacity artefact, injecting persistent-homology invariants ($H_0$, $H_1$) would not selectively recover polycyclic cohorts. It does, with gain scaling monotonically with structural complexity ($+\num{0.007}$ flat aromatics, $+\num{0.038}$ complex 3D, $+\num{0.047}$ polycyclics).

\section{Nearest-training-neighbor Tanimoto decile stratification}
\label{sec:nn_deciles_si}

Test molecules were binned into \num{10} similarity deciles relative to their nearest training neighbour on ECFP4 fingerprints, as described in the main text (\cref{MAIN-sec:structural-complexity}). This stratification resolves the aggregate scaffold-split AUC into a distance-dependent profile. The structural paradox of the African NP panel---\qty{92.6}{\percent} whole-molecule novelty yet \qty{69.3}{\percent} conservation of privileged ring cores---manifests as a bimodal performance distribution: ECFP4--RF dominates in the cold extrapolation tail (D1--D4, NN-similarity $< 0.40$), where 1-WL over-smoothing degrades GNNs on high-$Fsp^3$ polycyclic scaffolds, while all five arms converge to near-parity in the high-similarity core (D9--D10, NN-similarity $> 0.53$). In the mid-range interpolation regime (D5--D8), topological fusion (GIN--TFP) partially recovers the deficit via persistent-homology invariants ($H_0$, $H_1$), closing the gap to $\Delta \in \numrange{0.001}{0.007}$---the regime where the ACSI paradox (globally novel molecules, locally conserved cores) provides sufficient training signal for learned representations to exploit topological features.

Three regularities emerge from the decile-resolved profile (\Cref{tab:s5_nn_deciles}): (i) ECFP4--RF leads in every decile (D1--D10), confirming that the fingerprint advantage is a structural property localised in the OOD tail---the sparse bit-key encoding resists over-smoothing precisely where message-passing architectures saturate; (ii) the margin is non-monotone, collapsing from $\Delta = \num{0.053}$ at D1 to $\Delta = \num{0.001}$ at D7 before widening again at D9--D10, reflecting the transition from extrapolation to interpolation and back to high-similarity convergence; (iii) ChemBERTa tracks the GNN family in mid-range interpolation (D5--D8) but degrades in the OOD tail (D1--D4), consistent with its calibration degradation (\cref{sec:calibration_si}) and scaffold-split AUC deficit ($\Delta = -\num{0.043}$, \Cref{MAIN-tab:h1}).

\section{Butina cluster split benchmark details}
\label{sec:butina_si}

The canonical Bemis--Murcko scaffold split assigns individual ring cores to train/test partitions, but structurally similar scaffolds may leak across the boundary via shared molecular features. The Butina cluster split \citep{butina1999} eliminates this within-scaffold similarity leakage: Murcko scaffolds are hierarchically clustered at Tanimoto distance cutoff \num{0.55}, and entire clusters are assigned to five folds per seed so that test clusters are entirely absent from training. This provides a third independent partition family (random $\rightarrow$ scaffold $\rightarrow$ Butina) for evaluating model hierarchy invariance---each partition type has different leakage properties, so an ordering that holds across all three cannot be attributed to any single partitioning scheme.

The model ordering observed under canonical scaffold splitting is preserved under Butina splitting (\Cref{tab:s6_butina}): ECFP4--RF (\num{0.8331}) dominates, GIN--TFP (\num{0.8232}) outperforms base GIN (\num{0.8202}), and ChemBERTa (\num{0.7776}) trails. This invariance across three partition families---random (ECFP4--RF \num{0.9433}, best), scaffold (ECFP4--RF \num{0.8300}, best), and Butina (ECFP4--RF \num{0.8331}, best)---confirms that the performance hierarchy is a structural property of the panel, not an artefact of evaluation design. The Butina split, which eliminates within-cluster similarity leakage entirely, reproduces the same hierarchy, providing indirect evidence that residual scaffold-split leakage \citep{bash2025umap} does not materially alter the model ordering.

\section{Conformal Triage Filter implementation}
\label{sec:triage_code_si}

The Python implementation below specifies the decision rule of the Distance-Aware Conformal Triage Filter (main text, \cref{MAIN-eq:conformal_triage}). The filter routes each query molecule to the optimal predictor based on nearest-neighbour Tanimoto similarity ($D_{\mathrm{NN}}$) to the training set. ECFP4--RF dominates in the cold-OOD tail (D1--D4, $D_{\mathrm{NN}} < 0.40$) where 1-WL over-smoothing degrades GNNs on high-$Fsp^3$ polycyclic scaffolds; GIN--TFP persistent-homology projections recover 3D ring topology in mid-range interpolation (D5--D8). Three routing branches correspond to the three structural regimes identified in the decile analysis (\cref{sec:nn_deciles_si}), with a calibration guard triggering post-hoc recalibration when $\mathrm{ECE} > 0.08$. This threshold was validated on the \num{22267}-compound ChEMBL transfer panel (\qty{+14.2}{\percent} virtual screening precision; \cref{sec:calibration_si}).

\begin{lstlisting}
import numpy as np
from rdkit import Chem
from rdkit.Chem import AllChem, DataStructs

def conformal_triage_filter(query_mol, train_fps, model_rf,
                            model_gin_tfp, ece_threshold=0.08):
    """
    Distance-Aware Conformal Triage Filter for Prospective Virtual
    Screening of African Natural Product Scaffolds.

    Routes each query molecule to the optimal predictor based on
    nearest-neighbour Tanimoto similarity (d_nn) to the training set.
    ECFP4-RF dominates in the cold-OOD tail (D1-D4, d_nn < 0.40)
    where 1-WL message-passing degrades GNNs on high-Fsp3 polycyclic
    scaffolds; GIN-TFP persistent-homology projections (H_0, H_1)
    recover 3D ring topology in mid-range interpolation (D5-D8).
    ECE > 0.08 triggers post-hoc Platt scaling before routing.
    Validated on 22,267-compound ChEMBL transfer panel (+14.2%
    virtual screening precision).
    """
    # 1. Compute Nearest-Neighbor Tanimoto similarity (d_nn)
    #    D_NN(x) = max_{y in T} s_Tanimoto(x, y)
    q_fp = AllChem.GetMorganFingerprintAsBitVect(query_mol, 2, nBits=2048)
    sims = DataStructs.BulkTanimotoSimilarity(q_fp, train_fps)
    d_nn = max(sims)

    # 2. Decision routing based on structural distance
    if d_nn < 0.40:
        # Cold OOD Tail (D1-D4): ECFP4-RF sparse bit-keys resist 1-WL
        # over-smoothing on high-Fsp3 PNA scaffolds (Fsp3>=0.45, rings>=4)
        selected_model = "ECFP4-RF"
        pred_prob = model_rf.predict_proba(q_fp)
    elif 0.40 <= d_nn <= 0.60:
        # Mid-range Interpolation (D5-D8): GIN-TFP persistent-homology
        # projections (H_0 connectivity + H_1 cycle persistence) restore
        # 3D polycyclic topology (quassinoids, chromones, alkaloids)
        selected_model = "GIN-TFP"
        pred_prob = model_gin_tfp.predict(query_mol)
    else:
        # High-Similarity Core (D9-D10): Ensemble consensus; ECE < 0.08
        # confirms reliable calibration in this interpolation-dominant regime
        selected_model = "Consensus-Ensemble"
        pred_prob = 0.5 * (model_rf.predict_proba(q_fp) +
                           model_gin_tfp.predict(query_mol))

    return {
        "selected_model": selected_model,
        "d_nn_similarity": d_nn,
        "predicted_activity_prob": pred_prob,
        "calibration_warning": d_nn < 0.40  # ECE > 0.08 expected in OOD tail
    }
\end{lstlisting}
