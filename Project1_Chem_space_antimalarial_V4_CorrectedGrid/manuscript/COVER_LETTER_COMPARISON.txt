│ as an Article in JCIM (Manuscript ID: ci-2026-012015).                     │
│                                                                             │
│ This work presents a computationally benchmarked generative scaffold-      │
│ hopping framework for antimalarial discovery. Rather than a static hit     │
│ list, the framework retrospectively predicts (retrodicts) known ground-    │
│ truth antimalarials from the MMV Malaria Box before application to         │
│ African chemical space, achieving 69.8% hit rates and consensus-score      │
│ ROC-AUC 0.924–1.000. Among VAE-generated molecules, 92.6% access           │

│                                                                             │
│ The three-component pipeline—scaffold-aware VAE sampling, dual-filter      │
│ consensus docking (DiffDock + AutoDock Vina), and multi-parameter          │

│ are documented with open-source code, and the full dataset is deposited    │
│ on Zenodo (10.5281/zenodo.19608875).                                       │

┌─────────────────────────────────────────────────────────────────────────────┐
│ AFTER (3 pages) — Mission-Driven Narrative with Rigorous Validation        │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│ Dear Prof. Merz,                                                            │
│                                                                             │
│ We submit for consideration as an Article in the Journal of Chemical       │
│ Information and Modeling our manuscript "Computational Discovery of        │
│ Antimalarial Candidates from African Natural Product Chemical Space."      │
│ This work addresses a critical computational bottleneck in antimalarial    │
│ drug discovery: conventional virtual screening approaches require           │
│ screening tens of thousands of compounds per target (exceeding 1000        │
│ CPU-hours), making comprehensive multi-target exploration prohibitively    │
│ expensive for research groups in malaria-endemic regions where 94% of      │
│ global cases occur.                                                         │
│                                                                             │
│ ─────────────────────────────────────────────────────────────────────────  │
│ KEY INNOVATIONS AND SIGNIFICANCE:                                           │
│ ─────────────────────────────────────────────────────────────────────────  │
│                                                                             │
│ [1] RIGOROUSLY VALIDATED COMPUTATIONAL FRAMEWORK                            │
│                                                                             │
│ We developed a centroid-based screening protocol that achieves 99.3%       │
│ cost reduction (from 263,424 to 1,936 docking runs) while maintaining      │
│ pharmaceutical-grade predictive accuracy. Critically, we established       │
│ reliability through complementary validation strategies:                    │
│                                                                             │
│   • PROSPECTIVE DEKOIS external validation (PfDHFR, 40 actives + 1200     │
│     property-matched decoys) demonstrating that single-method AutoDock     │
│     Vina docking yields near-random enrichment (ROC-AUC 0.450)             │
│                                                                             │
│   • RETRODICTIVE CONSISTENCY against MMV Malaria Box positive-control      │
│     benchmark (399 confirmed antimalarial actives) where our dual-         │
│     consensus protocol (Vina + ML-based DiffDock rescoring) achieves       │
│     ROC-AUC 0.924–1.000 with bootstrap 95% CIs across four P. falciparum  │
│     resistance targets                                                      │
│                                                                             │
│ This dual-benchmark approach—combining prospective external decoy          │
│ discrimination with retrodictive in-distribution consistency—establishes   │
│ predictive validity before extrapolation to unexplored African natural     │
│ product space.                                                              │
│                                                                             │
│ ───────────────────────────────────────────────────────────────────────── │
│                                                                             │
│ [2] GENERATIVE SCAFFOLD-HOPPING BEYOND LOCAL INTERPOLATION                 │
│                                                                             │
│ Our ConvVAE-SMILES architecture systematically explores genuinely novel    │
│ chemical space: 92.6% of generated molecules are unreachable by local      │
│ SELFIES perturbations from known antimalarials (mean max Tanimoto 0.206    │
│ to seed compounds), yet scaffold recovery reaches 69.3% (70/101 bioactive  │
│ frameworks preserved).                                                      │
│                                                                             │
│ The apparent paradox is resolved through topological analysis: the 1.84×   │
│ scaffold-to-whole-molecule Tanimoto ratio demonstrates systematic          │
│ preservation of privileged ring systems while diversifying peripheral      │
│ substituents. STONED-SELFIES validation confirms: 97.9% of VAE-generated   │
│ molecules remain inaccessible even after 5,525 local mutations from        │
│ known drugs, empirically demonstrating scaffold-hopping rather than mere   │
│ interpolation.                                                              │
│                                                                             │
│ ───────────────────────────────────────────────────────────────────────── │
│                                                                             │
│ [3] SYSTEMATIC CHARACTERIZATION OF AFRICAN NP CHEMICAL SPACE               │
│                                                                             │
│ From 396 African natural products and 454 synthetic antimalarials, we      │
│ generated a 65,856-molecule hybrid library exhibiting 31.4% scaffold       │
│ diversity (20,702 unique Bemis–Murcko frameworks) with favorable drug-     │
│ likeness (94.1% Lipinski-compliant, 57.0% SYBA > 0 for synthetic          │
│ accessibility).                                                             │
│                                                                             │
│ Variational autoencoder clustering with KMeans identified 484 diverse      │
│ centroids for efficient multi-target screening against PfDHFR, PfCRT,      │
│ PfATP4, and PfClpP. The dual-filter consensus protocol (AutoDock Vina +    │
│ DiffDock) exploits the orthogonality between physics-based and ML-based    │
│ scoring (Spearman ρ = 0.1–0.4), reducing false positives by 12–45%         │
│ relative to single-method approaches while recovering 69.8% of MMV         │
│ Malaria Box actives.                                                        │
│                                                                             │
│ ───────────────────────────────────────────────────────────────────────── │
│                                                                             │
│ [4] COMPUTATIONALLY PRIORITIZED SYNTHESIZABLE LEADS                        │
│                                                                             │
│ Multi-parameter optimization integrating binding affinity, geometric       │
│ confidence, drug-likeness (QED), ADMET safety, and Lipinski compliance     │
│ identified 19,913 synthesizable leads (SYBA > 0) from 53 optimization-     │
│ worthy clusters. All 810 screened seed molecules with valid predictions    │
│ exhibited predicted selectivity index > 10.                                 │
│                                                                             │
│ We quantified the orthogonality between drug-likeness and binding          │
│ affinity through external Tartarus benchmark validation (19,913 molecules, │
│ Spearman ρ = 0.013, p = 0.091), confirming that MPO-based ranking          │
│ captures developability criteria independent of raw docking scores.        │
│                                                                             │
│ The complete computational workflow, validation protocols, and full        │
│ dataset are deposited as an open-access community resource:                │
│   • Zenodo DOI: 10.5281/zenodo.19608875                                   │
│   • GitHub: https://github.com/Vital-Sao/Malaria_codes                    │
│                                                                             │
│ ───────────────────────────────────────────────────────────────────────── │
│                                                                             │
│ [5] DEMOCRATIZING COMPUTATIONAL DRUG DISCOVERY IN ENDEMIC REGIONS          │
│                                                                             │
│ By reducing per-target screening requirements from >1000 CPU-hours to      │
│ <10 CPU-hours, this framework enables comprehensive multi-target           │
│ antimalarial screening on standard computational infrastructure. This      │
│ accessibility gain is particularly critical for research institutions in   │
│ malaria-endemic regions of sub-Saharan Africa, where 94% of global         │
│ malaria burden occurs but computational resources for drug discovery       │
│ remain severely limited.                                                    │
│                                                                             │
│ The validated efficiency-accuracy tradeoff establishes that resource-      │
│ constrained settings need not compromise predictive quality, positioning   │
│ local researchers to systematically explore regional chemical biodiversity │
│ for therapeutic candidates.                                                 │
│                                                                             │
│ ───────────────────────────────────────────────────────────────────────── │
│                                                                             │
│ RELEVANCE TO JCIM READERSHIP:                                              │
│                                                                             │
│ This work directly addresses core cheminformatics challenges:              │
│ (1) Generative molecular design with explicit validation of scaffold-      │
│     hopping versus interpolation                                            │
│ (2) Consensus scoring strategies for orthogonal computational evidence     │
│     integration                                                             │
│ (3) Benchmarking protocols combining prospective external validation       │
│     with retrodictive consistency checks                                    │
│ (4) Multi-parameter optimization frameworks balancing potency and          │
│     developability                                                          │
│ (5) Computational efficiency innovations enabling drug discovery in        │
│     resource-limited settings                                               │
│                                                                             │
│ The rigorous validation, open-source implementation, and complete data     │
│ dissemination align with JCIM's emphasis on reproducible computational     │
│ methodologies for chemical biology and drug discovery applications.        │
