# Historical audit and review index

**Updated:** 12 August 2026
**Purpose:** classify remaining audit snapshots and review records in one place without treating them as current scientific sources.
**Scope:** project Markdown outside `docs/archive/`, generated/third-party material, and the intentionally excluded P3 V2 work area.

## Reading rule

This index is a **navigation and provenance layer**. A listed document may contain correct information for its date, but it does not override the active data-analysis report (DAR), canonical manuscript, or current roadmap. For current scientific values, read the source in the **current canonical source** column first.

Status labels:

- `HISTORICAL_SNAPSHOT` — point-in-time assessment, audit, review, or fix queue;
- `MITIGATION_LOG` — adversarial review whose findings may have been incorporated, but whose historical narrative is retained;
- `PROVENANCE_DOSSIER` — review/register/signature material; not evidence of acceptance or experimental validation;
- `EXECUTION_CHECKPOINT` — dated job or preparation audit; not a cohort result;
- `ACTIVE_PLAN` — still operational and therefore not a historical result;
- `ACTIVE_SOURCE` — current DAR/roadmap/README/manifest; listed only to show the replacement source.

## Maintenance rule

When a new audit is completed, add one row here with its date, classification, and replacement source. Do not copy its numerical conclusions into a DAR without checking the underlying artifact. When an item becomes superseded, keep the original file for provenance and update only this index and the active source-of-truth document.
