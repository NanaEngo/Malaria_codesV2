## ACS LaTeX Class Limitation

**Important Technical Note:**

The `achemso` LaTeX document class used for ACS journal submissions **does not support** the `\orcid{}` command. This is why ORCID iDs are NOT included in the `.tex` source files.

Instead, ACS requires ORCID entry through the **Paragon Plus online submission system** only. This is standard procedure for all ACS journals.

**Do NOT attempt to add ORCIDs to the LaTeX source** - they will not compile and are not needed.
