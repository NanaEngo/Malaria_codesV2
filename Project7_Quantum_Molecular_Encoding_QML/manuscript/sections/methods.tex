\section{Methods}

% ── §1: Dataset ───────────────────────────────────────────────────────────────

\subsection{Datasets}

\subsubsection{P1 Set A — Proof-of-Concept Cohort}

We extracted \num{17} antimalarial candidate molecules from Project~1 Set~A\cite{sao2026p1},
a curated panel enriched for African natural product (ANP) structural motifs
prioritised by multi-parameter optimisation (MPO~$\geq 0.70$) and
Resistance-Resilience Score (RRS) across four malaria drug targets
(PfDHFR, PfCRT, PfATP4, PfClpP). The seed library was derived from
\num{396} ANP structures sourced from ANPDB\cite{betow2025} and
AfroDb\cite{ntie2017afrodb}, encompassing traditional antimalarial botanical
species including \textit{Cryptolepis sanguinolenta}, \textit{Enantia chlorantha},
and \textit{Nauclea latifolia}. All molecules were represented as canonical SMILES
strings and validated using RDKit\cite{rdkit}.

Activity labels (active/inactive) were derived from docking-score thresholds
applied in the upstream P1 multi-target triage workflow
(see \LED{001} for label assignment criteria). The final panel comprised
\num{15} inactive and \num{2} active molecules (class imbalance~15:2),
serving as the Phase~B smoke-test cohort.

\subsubsection{African-Chemotype Characterisation}

To quantify ANP structural identity, we computed three descriptors for each molecule:

\textbf{(i) Fraction sp\textsuperscript{3} carbons ($F_{sp^3}$):} ratio of
sp\textsuperscript{3}-hybridised carbons to total carbons\cite{lovering2009escape}.

\textbf{(ii) Stereocenter count:} enumerated via RDKit
\texttt{FindMolChiralCenters} after stereo assignment\cite{newman2020natural}.

\textbf{(iii) African-Chemotype Structural Index (ACSI):} mean Tanimoto
similarity (Morgan fingerprint, radius~$= 2$) to the five nearest neighbours
within the 396-member ANP reference set.

\subsubsection{P3 Benchmark — Canonical Scale Evaluation}

For canonical scale experiments, we used the \num{19849}-molecule P3 benchmark
dataset\cite{sao2026p3}, containing \num{15063} active and \num{4786} inactive
molecules (75.9\%/24.1\%). A stratified subsample of $n = 1000$ molecules
(seed~$= 42$; SHA-256: \texttt{04d6caa8...}; preserved class ratio) was drawn
for all computationally intensive QML experiments, following the precedent
established in Project~7 Phase~4. Canonical 5-fold stratified cross-validation
splits (seed~$= 42$) were frozen before execution.

% ── §2: Classical Baseline ────────────────────────────────────────────────────

\subsection{Classical Baseline: ECFP4--RBF SVM}

Extended-Connectivity Fingerprints (ECFP4)\cite{rogers2010} were generated
using RDKit (\texttt{GetMorganFingerprintAsBitVect}, radius~$= 2$, 2048~bits).
A support vector machine (SVM) with radial basis function (RBF) kernel was
trained using scikit-learn~(v1.7.1)\cite{sklearn}. Hyperparameters $C$ and
$\gamma$ were set to default values ($C = 1.0$, $\gamma = \texttt{scale}$).
On the P3 subsample ($n = 1000$), performance was evaluated under
5-fold stratified cross-validation (primary metric: AUC-ROC). This local
baseline (AUC~$0.869 \pm 0.027$) is directly comparable to QMSE results
at the same scale; the P3 canonical value (AUC~$0.9475$) is reproduced
from Project~3\cite{sao2026p3} for reference.

% ── §3: Quantum Molecular Encoding ───────────────────────────────────────────

\subsection{Quantum Molecular Encoding}
\label{sec:qmse}

QMSE encodes molecular graph topology, bond polarity, and stereochemistry
directly as rotation angles in a parameterised quantum circuit, bypassing
fingerprint hashing entirely. We follow the BondFeatureMap framework of
Boy et al.\cite{boy2025}.

\subsubsection{BondOrderMatrix}

The BondOrderMatrix $\mathbf{M} \in \mathbb{R}^{n \times n}$ for a molecule
with $n$ heavy atoms encodes:

\begin{equation}
\mathbf{M}_{ij} =
\begin{cases}
0.5 \times Z_i^{2.4}           & i = j \\[4pt]
\dfrac{Z_i \times Z_j}{b_{ij}} & i \neq j,\; \text{bonded} \\[2pt]
0                               & i \neq j,\; \text{not bonded}
\end{cases}
\end{equation}

where $Z_i$ is the atomic number of atom~$i$ and $b_{ij}$ the bond order
(1 = single, 1.5 = aromatic, 2 = double, 3 = triple).
\textbf{Stereochemical flags:} S-configuration stereocenters are assigned
negative diagonal elements ($\mathbf{M}_{ii} < 0$); Z-configuration double
bonds are assigned negative off-diagonal elements ($\mathbf{M}_{ij} < 0$).
This allows the quantum state to distinguish enantiomers and geometric isomers
without any external chirality label\cite{boy2025}.

\subsubsection{CoulombMatrix}

The CoulombMatrix\cite{rupp2012} adapts the electrostatic interaction matrix
to a bonded representation compatible with the BondFeatureMap circuit:

\begin{equation}
\mathbf{C}_{ij} =
\begin{cases}
0.5 \times Z_i^{2.4}                     & i = j \\[4pt]
\dfrac{Z_i \times Z_j}{d_{ij}^{\,\text{bond}}} & i \neq j,\; \text{bonded}
\end{cases}
\end{equation}

where $d_{ij}^{\,\text{bond}}$ is the average bond length between atom types
$i$ and $j$ (IUPAC/CRC Handbook values; 24 bond-pair entries added for
medicinal-chemistry motifs: C--F, C--Cl, C--Br, C--I, N--S, O--S, C--P,
P=O, B--C/N/O, \textit{etc.}). The CoulombMatrix formulation was used as
the canonical encoding type for Phase~C/D experiments following HPO
selection.

\subsubsection{Angle Extraction and Qubit Register}
\label{sec:angles}

From either matrix, angle vectors are extracted for the $n_q$-qubit register
by truncating the molecule to its first $n_q$ heavy atoms:

\begin{itemize}
  \item \textbf{Single-qubit angles} ($n_q$ values): $\phi_i = \mathbf{M}_{ii}$,
        applied as $R_X(\phi_i)$ to qubit~$i$.
  \item \textbf{Two-qubit angles} ($\binom{n_q}{2}$ values):
        $\phi_{ij} = \mathbf{M}_{ij}$, applied as
        $R_{YY}(\phi_{ij})$ (IsingYY) to qubit pairs $(i, j)$.
\end{itemize}

\textbf{Truncation constraint.} The canonical Phase~D configuration uses
$n_q = 8$ qubits, encoding the first eight heavy atoms only. For drug-sized
ANP molecules with 12--28 heavy atoms, stereocenters at atom index~$\geq 8$
are outside the encoding window and produce identical angle vectors for both
enantiomers. This is the primary architectural bottleneck characterised by
the stereo probe in Section~\ref{sec:stereo_probe_methods} and
Table~\ref{tab:stereo_probe}.

The Phase~D QMSE circuit follows the BondFeatureMap architecture of
Boy et al.\cite{boy2025}, with entangling layer fixed to IsingYY
(selected by Phase~C HPO from \{RXX, RYY, RZZ, CNOT, CZ, none\}).
For $n_q = 8$ and depth~2, the circuit has $8 + 28 = 36$ encoding angles
per molecule per layer, for a total encoding depth of 72 two-argument
rotation operations. No additional variational parameters are trained
in the quantum layer; all trainable weights reside in the TF dense head
(Section~\ref{sec:tfhead}).

% ── §4: QMSE–TF Hybrid Model ─────────────────────────────────────────────────

\subsection{QMSE--TF Hybrid Model}
\label{sec:tfhead}

\subsubsection{Architecture}

The QMSE--TF hybrid model combines a PennyLane quantum layer with a
TensorFlow~2.18.0\cite{tensorflow2015} classical head in a single
end-to-end differentiable pipeline:

\begin{enumerate}
  \item \textbf{QMSE encoding} (Section~\ref{sec:angles}): SMILES
        $\to$ CoulombMatrix $\to$ angle vectors ($\phi_\text{diag}$,
        $\phi_\text{off}$).

  \item \textbf{Quantum layer (\texttt{QMSELayer})}: a custom
        \texttt{tf.keras.Layer} subclass wrapping the PennyLane QNode.
        Input: angle vectors. Output: 8-dimensional
        $\langle Z_q \rangle$ expectation-value vector. Differentiation:
        \texttt{diff\_method=`backprop'} (statevector interface, exact
        gradients via \texttt{tf.GradientTape}).

  \item \textbf{TF dense head}: three \texttt{Dense(128, activation=`relu')}
        layers with \texttt{BatchNormalization} and
        \texttt{Dropout(0.204)}\footnote{Dropout rate selected by Phase~C HPO.
        See Table~\ref{tab:hpo_space}.},
        followed by \texttt{Dense(1, activation=`sigmoid')} for binary
        activity prediction.
\end{enumerate}

The quantum and classical components are co-optimised in a single training
loop via \texttt{tf.GradientTape}, propagating gradients through both the
TF dense head and the quantum circuit simultaneously. No separate
pre-training or frozen-layer strategy is used.

\subsubsection{Training Protocol}

\begin{itemize}
  \item \textbf{Optimiser:} AdamW\cite{loshchilov2019decoupled}
        ($\text{lr} = 3.17 \times 10^{-4}$,
         $\text{weight\_decay} = 4.60 \times 10^{-5}$;
         values from Phase~C HPO best configuration).
  \item \textbf{Loss:} binary cross-entropy.
  \item \textbf{Batch size:} 16.
  \item \textbf{Epochs:} 80 maximum.
  \item \textbf{Early stopping:} patience~$= 10$ epochs on validation loss
        (no improvement threshold $= 10^{-4}$).
  \item \textbf{Class weighting:} none; class imbalance (75.9\% active)
        accounted for by AUC-ROC as primary metric.
  \item \textbf{Gradient monitoring:} mean $\|\nabla_\theta L\|$ recorded
        per fold; batches with norm~$< 10^{-6}$ flagged as barren-plateau
        indicators.
\end{itemize}

\subsubsection{Evaluation Protocol}

Phase~D canonical evaluation used 5-fold stratified cross-validation on the
frozen $n = 1000$ P3 subsample (seed~$= 42$; NPZ SHA-256:
\texttt{dff5cc71...}). Primary metric: AUC-ROC. Secondary metrics: Brier
score, accuracy, F1. Per-fold values and mean~$\pm$~SD are reported.

% ── §6: Quantum Kernel SVM (Aer) ─────────────────────────────────────────────

\subsection{Quantum Kernel SVM (Qiskit Aer)}
\label{sec:stereo_probe_methods}

\subsubsection{Stereo-Discrimination Probe}

To characterise the stereochemical encoding capacity of QMSE independently
of the TF hybrid pipeline, we computed exact quantum kernel values for paired
stereoisomers using Qiskit~1.2.4\cite{qiskit} with the Aer statevector
simulator (local, no IBM connection). For five R/S molecular pairs and three
Z/E pairs, the kernel fidelity

\begin{equation}
K(A, B) = |\langle\psi_A|\psi_B\rangle|^2
\end{equation}

was computed using full-molecule encoding ($n_q = n_{\text{atoms}}$,
no truncation) at depth~2, IsingZZ entangling. The discrimination metric
$\Delta K = K(X, X) - K(R, S)$ (or $K(E, E) - K(E, Z)$) measures how
well the quantum state space separates stereoisomers: $\Delta K \approx 1$
indicates near-orthogonal states; $\Delta K \approx 0$ indicates
indistinguishable states.

\subsubsection{IBM Aer Kernel SVM — P1 Set A (Supplementary Evaluation)}

As a supplementary evaluation, the BondOrderMatrix quantum kernel was
computed for all $17 \times 17 = 289$ molecule pairs in P1 Set~A
($n = 17$, $n_q = 17$ qubits padded to a common register, depth~2,
IsingZZ, Qiskit Aer statevector; runtime 72~s, 153 unique entries).
Kernel Target Alignment (KTA; Section~\ref{sec:stats}) was computed
to assess label alignment independently of SVM performance. LOO-CV SVM
AUC is reported for completeness but is \emph{not} interpreted as a
performance metric due to the extreme class imbalance (15 inactive,
2 active); KTA is the informative quantity.

% ── §7: Statistical Analysis ─────────────────────────────────────────────────

\subsection{Statistical Analysis}
\label{sec:stats}

\subsubsection{Performance Metrics}

Primary metric: AUC-ROC (rank-based, robust to class imbalance).
Secondary metrics: Brier score, accuracy, F1-score. Mean and SD are
computed across CV folds; paired $t$-tests use fold-level values.

\subsubsection{QMSE vs.\ Classical Comparison}

Performance difference between QMSE--TF hybrid and ECFP4-RBF SVM was
assessed by a paired $t$-test on per-fold AUC values (5 folds,
$\alpha = 0.05$, two-tailed). Effect size: Cohen's~$d$. Following the
honest-negative precedent of Project~3\cite{sao2026p3}, outcomes are
classified as:

\begin{itemize}
  \item \textbf{Scenario~A (advantage):}
        $\Delta\text{AUC} \geq 0.01$ and $p < 0.05$.
  \item \textbf{Scenario~B (equivalence):}
        $|\Delta\text{AUC}| < 0.01$ or $p \geq 0.05$.
  \item \textbf{Scenario~C (underperformance):}
        $\Delta\text{AUC} < -0.01$ and $p < 0.05$.
\end{itemize}

\subsubsection{Kernel Target Alignment}
\label{sec:kta}

KTA\cite{cristianini2002} measures the alignment between the kernel matrix
$\mathbf{K}$ and the ideal label kernel $\mathbf{y}\mathbf{y}^\top$:

\begin{equation}
\text{KTA} = \frac{
  \langle \mathbf{K},\, \mathbf{y}\mathbf{y}^\top \rangle_F
}{
  \|\mathbf{K}\|_F\; \|\mathbf{y}\mathbf{y}^\top\|_F
}
\end{equation}

where $\langle \cdot, \cdot \rangle_F$ is the Frobenius inner product.
KTA~$\in [-1, 1]$; values near zero indicate no correlation; positive
values indicate activity-aligned kernel structure independent of SVM
classification.
