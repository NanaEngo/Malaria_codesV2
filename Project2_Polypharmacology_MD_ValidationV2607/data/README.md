# Data Directory

## 📁 Directory Structure

```
data/
├── external/           # External datasets and reference data
├── from_project1/      # Symbolic links to Project 1 data (DO NOT MODIFY)
├── ligands/           # Prepared ligand structures for MD
├── md_inputs/         # MD simulation input files
└── proteins/          # Protein structures and mutant variants
```

## 📋 Data Management Guidelines

### 🔗 Project 1 Integration
The `from_project1/` directory contains **symbolic links** to Project 1 data:
- **DO NOT** modify files in this directory
- **DO NOT** copy large files - use symbolic links
- Links point to: `../../../Docking/`, `../../../clustering/`, etc.

### 📊 Data Types

#### External Data (`external/`)
- Reference datasets from literature
- Experimental validation data
- Public database downloads (ChEMBL, PDB, etc.)
- **Size**: Small to medium files (<100 MB each)

#### Ligand Data (`ligands/`)
- Prepared ligand structures (.sdf, .mol2, .pdb)
- Protonation states and conformers
- Force field parameters
- **Generated by**: `scripts/md/md_prepare_ligands.py`

#### MD Input Files (`md_inputs/`)
- GROMACS topology files (.top, .itp)
- Parameter files (.mdp)
- Initial coordinates (.gro, .pdb)
- **Generated by**: MD preparation scripts

#### Protein Data (`proteins/`)
- Wild-type protein structures
- Mutant variants (resistance mutations)
- Homology models
- **Generated by**: `scripts/md/md_homology_mutants.py`

## 🚫 What NOT to Store Here

- **Large trajectory files** → Use `results/trajectories/` (git-ignored)
- **Temporary files** → Use `/tmp/` or local scratch
- **Duplicated Project 1 data** → Use symbolic links instead
- **Generated analysis results** → Use `results/` directory

## 🔄 Data Processing Workflow

1. **Candidate Selection** → `results/candidate_selection/`
2. **Ligand Preparation** → `data/ligands/`
3. **Protein Preparation** → `data/proteins/`
4. **System Assembly** → `data/md_inputs/`
5. **MD Simulation** → `results/trajectories/`
6. **Analysis** → `results/analysis/`

## 📋 Data Validation Checklist

Before running MD simulations, verify:
- [ ] All ligands have valid 3D coordinates
- [ ] Protein structures are properly prepared (hydrogens, caps)
- [ ] Force field parameters are complete
- [ ] System topology files are error-free
- [ ] Symbolic links to Project 1 data are intact
