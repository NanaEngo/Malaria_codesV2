# PDF Repair Log - P2 Manuscript

**Date:** 2026-09-08  
**Issue:** libxpdf xref table corruption in `rmsd_representative.pdf`

## Problem

When compiling `Polypharmacology_MD_Validation_V2609.tex`, the following error appeared:

```
libxpdf: Syntax Error: Couldn't read xref table
libxpdf: Syntax Warning: PDF file is damaged - attempting to reconstruct xref table...
```

This error was triggered when LaTeX attempted to include `Graphics/rmsd_representative.pdf` on page 16 of the main document.

## Root Cause

The PDF file `rmsd_representative.pdf` had a corrupted internal xref (cross-reference) table. This is a common issue with PDFs generated by Matplotlib when the file writing process is interrupted or when there are encoding issues.

## Solution

The corrupted PDF was repaired using Ghostscript's PDF rewriting capability:

```bash
cd Project2_Polypharmacology_MD_ValidationV2607/manuscript/LaTeX/Graphics
cp rmsd_representative.pdf rmsd_representative_corrupted.pdf
gs -o rmsd_representative_fixed.pdf -sDEVICE=pdfwrite -dPDFSETTINGS=/prepress rmsd_representative_corrupted.pdf
mv rmsd_representative_fixed.pdf rmsd_representative.pdf
```

This process:
1. Backed up the corrupted file as `rmsd_representative_corrupted.pdf`
2. Used Ghostscript to read and reconstruct the PDF with a valid internal structure
3. Replaced the corrupted file with the repaired version

## Prevention

To prevent similar issues in the future:
1. Use `matplotlib.pyplot.savefig()` with `bbox_inches='tight'` parameter
2. Consider using `pdf.compression = 6` for better PDF structure
3. Verify PDF integrity after generation with `pdfinfo` before committing
4. Keep PNG versions as fallback sources

## Command Reference

Check PDF integrity:
```bash
pdfinfo filename.pdf
```

Repair corrupted PDF:
```bash
gs -o output.pdf -sDEVICE=pdfwrite -dPDFSETTINGS=/prepress input.pdf
```

Convert PNG to PDF (if needed):
```bash
convert input.png -quality 100 output.pdf
```
